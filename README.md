# LP制作サンプル

カフェLPとヘアアイロンLPの、HTML・CSS・JavaScriptによる実装サンプルです。

## 構成

- `index.html` / `style.css` / `script.js`: カフェLP
- `hair-iron-lp/`: ヘアアイロンLP
- `assets/`: 各LPで使用するローカル画像

## 技術

- HTML5
- CSS3（レスポンシブ対応）
- Vanilla JavaScript

本リポジトリは学習・ポートフォリオ用の架空案件サンプルです。掲載されている商品名、価格、効果、レビュー等は実在の商品・サービスを示すものではありません。

画像はUnsplash等の素材を使用しています。公開時は各素材の利用規約を確認してください。
